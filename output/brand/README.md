# Open My Map 品牌设计素材

本目录收录本轮 Logo 探索的全部 **34 张 PNG**、设计说明及生成提示词。素材由内置 imagegen 生成，按探索顺序归档。

这些文件是供比较与继续精修的概念稿。目前未指定最终采用版本，也未替换应用中的标志。除第一版独立标志外，其余 PNG 的暖白背景与负形均未处理为透明通道；所有版本尚未矢量化或完成 favicon、小尺寸及印刷适配。
