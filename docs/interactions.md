# 地图交互范围与验收

本项目参考 Google Maps 的交互惯例，底图、地点资料和路线服务仍由高德地图提供。首页管理、项目、图层、要素与附件属于本应用；未接入 Google Maps Platform，也不宣称与 Google Maps 原生产品完全一致。

本轮覆盖路线、地点搜索与详情、位置菜单、持续测量、绘制快捷键、图层样式与排序、移动端面板、只读权限和编辑历史。不扩展 3D、旋转、指南针或街景。

## 对照标准

以下 Google 官方帮助页用于定义操作标准，而非作为本项目的地图或地点数据源。链接于 2026-10-14 核验。

- G1：[在 Google 地图中查询和显示路线](https://support.google.com/maps/answer/144339?hl=zh-Hans)：起终点、出行方式、备选路线、多目的地及顺序。
- G2：[测量点与点之间的距离](https://support.google.com/maps/answer/1628031?hl=zh-Hans)：逐点测量、调整位置和移除测量点。
- G3：[使用 Google 地图搜索各类地点](https://support.google.com/maps/answer/3092445?hl=zh-Hans)：关键词搜索、地点资料和当前地图区域。
- G4：[创建或打开地图](https://support.google.com/mymaps/answer/3024454?hl=zh-Hans)：自定义地图的创建与管理。
- G5：[使用地图图层](https://support.google.com/mymaps/answer/3024933?hl=zh-Hans)：图层组织、样式和对象管理。
- G6：[向您的地图添加地点](https://support.google.com/mymaps/answer/3024925?hl=zh-Hans)：添加地点及地点样式。

底部面板三态、面积、服务器编辑历史和并发保护是本项目明确的验收标准，不借这些帮助页声称 Google 原生产品具备相同实现。

## 验证环境与证据

验证日期为 2026-10-14。后端使用隔离 SQLite 数据库及上传目录，浏览器使用 Chromium、实际 React 页面和实际 API。首次验收时环境未配置 `VITE_AMAP_KEY`，无配置状态已单独验证；随后已配置本地高德 Web 密钥并完成以下在线验收。密钥和安全密钥保存在被 Git 忽略的环境文件中，未写入源码。

地图交互测试通过临时浏览器网络拦截替换 SDK 加载器，并使用显式标注的 AMap SDK 契约替身。替身与截图未加入应用。替身可以检查坐标转换、回调解析、交互状态、异步竞争、错误处理和持久化；不能证明真实高德瓦片、热点命中、在线路线数量、路线质量或 SDK 内部手势行为。

证据编号对应交付的 JSON 报告中 `cases` 数组顺序，序号从 1 开始：

- B01–B31：浏览器交互与实际后端集成报告 `open-my-map-interactions-browser.json`。
- A01–A12：隔离后端 API 与事务验收报告 `open-my-map-interactions-backend.json`。
- R01–R05：真实 React 路线组件专项报告 `open-my-map-directions-regressions.json`。

这些报告在交付 artifacts 中，不含密钥或登录会话。临时 SDK 替身不作为生产地图方案交付。

## 历史与附件边界

核心地图内容编辑使用服务端 checkpoint。恢复同时校验内容指纹；协作变化后拒绝旧恢复并保留最新内容。历史不跨地图或跨用户恢复，也不恢复已删除的媒体文件。

新增或删除附件、永久删除含附件的要素或图层会清空编辑历史。服务端同时校验附件集合，媒体变化后拒绝不再适用的 checkpoint；不会用历史快照复活已经删除的文件。回收站的保留和恢复属于独立的地图管理功能。

## 后续真实高德在线验收（2026-10-14）

已使用真实高德 JSAPI 2.0、地图瓦片与在线服务验证；这轮 UI 检查没有 SDK 替身或服务响应替换。桌面视口为 1280×853，手机视口为 390×844，均使用系统 Chromium。

- 真实标准底图、卫星底图、路况图层及缩放按钮正常；地图加载后不再误报超时。
- 搜索“上海外滩”返回真实列表、地点详情和坐标；添加到图层后可从实际后端重新读取。
- 驾车、步行、骑行服务均返回有效道路路径、距离、时长和分步指引。
- 通过界面选择“上海人民广场”和“外滩”，规划并保存路线；geometry 与站点 metadata 持久化。
- 手机路线面板、地图与保存流程正常，无横向溢出；没有页面运行时错误或控制台错误。

实测修复了两处真实 SDK 差异：隐藏的卫星、路网和路况图层不再附加到地图，避免 `Map.complete` 永不触发；视野避让改用官方“上、下、左、右”顺序并通过官方接口计算最大缩放。

当前云端浏览器被高德识别为非 WebGL 的 DOM 兼容渲染模式。该模式能显示真实瓦片，但 SDK 的 `setMapStyle` 不执行浅色主题切换。因此本环境未验证浅色主题的实际颜色，仍应在支持高德 WebGL 渲染的浏览器中确认。地图移动和缩放会取消已不需要的瓦片请求，`ERR_ABORTED` 属于这一正常过程。

交付截图为本轮真实地图、地点和路线；旧的 SDK 替身截图仍保留其明确标记，不作为本轮在线验证证据。仍需补充真实手机硬件手势、原生 POI 热点点击、道路拖动重算和全部在线失败场景。
