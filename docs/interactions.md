# 地图交互范围与验收

本项目的编辑器目标是 **Google My Maps：创建、组织和分享自定义“我的地图”的网页**。首页排版以用户提供的首页参考图为准；底图、地点资料和道路规划继续由高德地图提供。首页管理、项目、图层、要素与附件属于本应用，未接入 Google Maps Platform。

本轮对齐地图创作工作流：持久地图管理栏、地图顶部搜索与绘制工具、独立路线图层和图层栏中的底图选择。普通 Google Maps 的商业地点详情、备选路线、路况和移动端三态面板是本项目附加能力，不能用这些功能的通过记录代替 My Maps 对齐验收。

## 历史与附件边界

核心地图内容编辑使用服务端 checkpoint。恢复同时校验内容指纹；协作变化后拒绝旧恢复并保留最新内容。历史不跨地图或跨用户恢复，也不恢复已删除的媒体文件。

新增或删除附件、永久删除含附件的要素或图层会清空编辑历史。服务端同时校验附件集合，媒体变化后拒绝不再适用的 checkpoint；不会用历史快照复活已经删除的文件。回收站的保留和恢复属于独立的地图管理功能。

## 此前真实高德在线验收（2026-10-14）

此前已使用真实高德 JSAPI 2.0、地图瓦片与在线服务验证；该轮 UI 检查没有 SDK 替身或服务响应替换。桌面视口为 1280×853，手机视口为 390×844，均使用系统 Chromium。这些结果证明下列高德接入能力，不证明本轮 My Maps 布局和工作流已对齐。

- 真实标准底图、卫星底图、路况图层及缩放按钮正常；地图加载后不再误报超时。
- 搜索“上海外滩”返回真实列表、地点详情和坐标；添加到图层后可从实际后端重新读取。
- 驾车、步行、骑行服务均返回有效道路路径、距离、时长和分步指引。
- 通过界面选择“上海人民广场”和“外滩”，规划并保存路线；geometry 与站点 metadata 持久化。
- 手机路线面板、地图与保存流程正常，无横向溢出；没有页面运行时错误或控制台错误。

实测修复了两处真实 SDK 差异：隐藏的卫星、路网和路况图层不再附加到地图，避免 `Map.complete` 永不触发；视野避让改用官方“上、下、左、右”顺序并通过官方接口计算最大缩放。

当前云端浏览器被高德识别为非 WebGL 的 DOM 兼容渲染模式。该模式能显示真实瓦片，但 SDK 的 `setMapStyle` 不执行浅色主题切换。因此本环境未验证浅色主题的实际颜色，仍应在支持高德 WebGL 渲染的浏览器中确认。地图移动和缩放会取消已不需要的瓦片请求，`ERR_ABORTED` 属于这一正常过程。

该轮交付截图为真实地图、地点和路线；更早的 SDK 替身截图仍保留其明确标记，不作为真实高德在线验证证据。仍需补充真实手机硬件手势、原生 POI 热点点击、道路拖动重算和全部在线失败场景。

1. 底图实际加载；标准、卫星、浅色与路况切换；真实 POI 热点命中。
2. 实际地点搜索、分页、详情、照片及视口搜索，核对服务返回的资料与位置。
3. 驾车、步行、骑行及多站点路线，核对候选数量、道路形状、时长和道路拖动重算。
4. 桌面与真实触屏设备上的地图平移、缩放、点拖动、顶点编辑、长按和底部面板。

没有 Key 或线上服务失败时，页面显示配置提示或实际错误；应用不会以示例瓦片、虚构地点或直线冒充高德服务。
